# 健康饮食科普资料

整理日期：2026-10-08。

这套资料把公开的权威说法收成一份可查阅的底稿，方便做科普文章、讲座提纲或海报文案。它不是个人饮食处方，也不能代替医生、临床营养师的面对面建议。孕期、婴幼儿、老年人、慢性病和正在用药的人，吃法要结合自身情况。

## 数字从哪来

定量建议优先采用三类一手来源：

1. 中国营养学会《中国居民膳食指南（2022）》官方公告、发布会实录，以及平衡膳食宝塔、餐盘的解析说明。
2. 世界卫生组织《健康饮食》事实清单（页面标注日期 2026-01-26）。
3. 国民营养健康指导委员会办公室 2024 年 4 月印发的“减油、增豆、加奶”核心信息；体重分类采用国家卫生健康委《体重管理指导原则（2024年版）》所引《成人体重判定》（WS/T 428-2013）。

同一主题若中外口径不完全相同，正文会并列写出，并说明各自适用的人群。例如成年人食盐，两边都是每天不超过 5 克；蔬菜水果，世卫组织按“合计至少 400 克”表述，中国指南分开写“蔬菜至少 300 克、水果 200～350 克”。

监测数据（超重肥胖、高血压、用盐用油）来自 2022 年指南发布会引用的当时监测结果，年份写在句子里。它们说明“为什么要改吃法”，不是 2026 年的最新全国数字。

## 写作时请守住的边界

- 指南面向的是一般健康人。宝塔上的克数，对应的是一段时间内、能量需要大约 1600～2400 千卡的成年人，不是每一餐都必须卡在同一个数上。
- “多吃”“适量”“不超过”都是指南里的定量用语，科普时尽量带上克数或频次，避免再被理解成“越多越好”或“完全不能吃”。
- 食物重量除特别注明外，指可食部的生重或指南原文所用口径。烹调后会缩水或吸水，家庭称重只作大致参照。
- 不要把营养补充剂写成可以替代饭菜。指南把补充剂放在膳食不够、或特定生理阶段（如婴儿维生素 D、备孕叶酸）的位置上。
